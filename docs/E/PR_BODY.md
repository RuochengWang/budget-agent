## 如何启动

```bash
uv sync --frozen --extra dev --extra ui
uv run streamlit run app.py
```

在「运行」页选择「离线演示替身」，可试球鞋或日用品案例；完成一次运行后可切换到「历史回放」。如需验证「正式模块」，仅在测试机器本地配置学校模型密钥，再切换运行方式；不需要改 TOML，也不要上传密钥或记录。

## 如何验证

```bash
uv run pytest -q
uv run ruff check .
uv run python -m evaluation.integration_probe
```

本地以远端主线 `3a9a6ed` 为基准：**176 passed，0 xfailed**；Ruff、`git diff --check`、四案例离线联调通过。界面测试确认正式运行记录使用 90/540 秒配置，未配置密钥时保留 `real/partial`，不会降为演示。测试及探针不请求学校 API。
