# 报告模板（E 整合，全员供稿）

本文件尚无实验结果。不要把占位项写成已经完成。

## 任务与范围（A）
目标用户、输入输出、第一版支持的优惠与未支持场景。

## 方法（各负责人）
- A：协议、流程、模型与异常控制。
- B：预算公式、理性策略。
- C：优惠假设、枚举与正确性验证。
- D：角色、工具策略、交叉回应与最终约束。
- E：界面、数据集、评测流程。

## 实验设置（E，A 确认）
冻结 commit、数据/提示词版本、模型 ID、配置、开发/测试划分、独立人工标签、
统一工具额度与调用成本。列出 B0/B1/B2/M 和至少一个消融。

## 结果（待真实运行）
每个指标写清有效样本数、分母、误差与失败案例。不要用模型自评证明正确，
不要把多角色输出更长当作质量更好。主观评分披露组内评价。

## 局限与贡献（全员）
数据快照、优惠规则、自主性边界、时间/调用开销、样本规模与评分偏差。
按实际提交与验收记录填写贡献，预定分工不等于最终贡献。
